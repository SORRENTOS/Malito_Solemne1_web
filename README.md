## Descripción

Destino Cordillera es un sitio web que tiene como finalidad promocionar actividades turísticas.
La web se divide en los siguientes apartados:

- Panoramas
- Alojamiento y Gastronomía
- Reservas y contacto

## Instrucciones para ejecutar el sitio

1. Clone o descargue el repositorio desde la rama **main**
2. Una vez descargado, ingrese a la raíz del proyecto
3. Ya en la raíz, haga doble click en `index.html` y espere que se abra el navegador (asegúrese de tener un navegador compatible con HTML5)

## Tecnologías usadas

Para la realización de este proyecto se usaron las siguientes tecnologías:

- HTML5
